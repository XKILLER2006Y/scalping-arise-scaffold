# Models

## `real_xgb_model.pkl` (172 KB) — experimental, use with caution

- **Trained on:** `data/real_paxg_1m.csv` — PAXG/USD (Pax Gold crypto token) 1-minute bars,
  10,082 rows ≈ 7 days (2026-08-27 → 2026-09-03). Script: `backend/simulation/train_real_model.py`.
- **NOT XAU/USD spot.** PAXG tracks gold but has different spreads, liquidity, sessions,
  and microstructure. Treat this model as a crypto-proxy experiment, not a gold model.
- **Target:** 1 if close is higher 5 minutes ahead, else 0. Features (10):
  `return, log_return, volatility_14, gk_vol, buy_pressure, cvd, rsi_14, dist_sma9, dist_sma21, volume`.
- **Limits:** 7-day sample, no walk-forward validation, no saved accuracy report.
  Retrain on real XAU/USD spot history before trusting it: collect 1m spot data,
  rerun the training script pointed at it, and record out-of-sample accuracy here.
- Loaded by `backend/app/intelligence/sentiment.py` (first candidate path).

## `quarantined/` — DO NOT USE

`xgb_model.RANDOM-DATA-DO-NOT-USE.pkl` was generated by training on
`numpy.random` dummy data (`ml_model.py` scaffolding). Its predictions are
meaningless. It is kept only as a reminder, outside every model load path.
Nothing in the codebase may load from `quarantined/`.
